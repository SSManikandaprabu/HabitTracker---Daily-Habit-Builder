# HabitTracker - Daily Habit Builder & Streak Suite

A daily habit tracking web application featuring interactive completion grids, streak counters, and habit consistency analytics.

## Features

- Add, customize, and manage daily positive habits with custom emoji icons and frequency targets
- Interactive daily completion checklist with instant toggle feedback
- **Automated streak tracking**: Automated streak tracking: current streak and longest consecutive streak
- Visual GitHub-style contribution heat map showing completion consistency over time
- Category filters (Health, Study, Fitness, Mindfulness, Productivity)
- Data persistence using browser LocalStorage with export/import backup options

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Tailwind CSS
- LocalStorage API

## Installation & Setup

This is a standalone, client-side web application. No complex build pipelines, database configurations, or package installations are required.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SSManikandaprabu/HabitTracker---Daily-Habit-Builder.git
   cd HabitTracker---Daily-Habit-Builder
   ```

2. **Run the application:**
   - **Direct Browser Launch**: Double-click `habittracker_daily_habit_builder_streak_suite.html` to open it directly in any modern web browser (Chrome, Firefox, Safari, Edge).
   - **Or via Local HTTP Server**:
     ```bash
     python -m http.server 8000
     ```
     Then open [http://localhost:8000/habittracker_daily_habit_builder_streak_suite.html](http://localhost:8000/habittracker_daily_habit_builder_streak_suite.html) in your browser.

## Usage

1. Launch the application in your browser following the setup instructions above.
2. Interact with the application controls and input fields tailored for HabitTracker - Daily Habit Builder & Streak Suite.
3. Preferences and data are stored locally in your browser's LocalStorage where applicable.

## Environment Variables

None required. All habit records persist locally in LocalStorage.
